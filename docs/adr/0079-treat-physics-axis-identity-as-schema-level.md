# Treat Physics Axis identity as schema-level

Exactly 16 Physics Ontology Axis identities and the scientific question each Axis asks belong to the global schema rather than to the ordinary Controlled Term lifecycle. Labels may change without changing identity, but adding, removing, merging, or semantically changing an Axis requires a new schema version and an explicit tested migration; terms within an Axis continue to use normal Controlled Term governance. No extra Axis is invented merely to preserve a stale count.
