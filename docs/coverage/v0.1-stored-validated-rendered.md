## Reader-layer contract

The fixed route set is `/`, `/papers`, `/papers/[work-id]`,
`/research-lines/[id]`, and `/learning-paths/[id]`. Work Reader View exposes
the title, Scientific takeaway, problem, assumptions, Scientific delta,
Physical Account, Physics Ontology, Methods, and reason to read. Provenance
Detail is a native HTML disclosure containing Version metadata, concrete
Version Evidence, typed locators, publication correspondence, and relevant
review context. Core content is generated HTML and the pages contain no client
JavaScript.

Draft Works, hidden/unreviewed records, and draft editorial entities are absent
from reader-facing projections and indexes. The reverse index at
`generated/work-research-lines.json` is derived from `content/`, ignored by
Git, reproducible byte-for-byte, and removable. Re-running `npm run build`
regenerates it; no generated artifact is a visibility-digest input.
