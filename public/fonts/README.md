# Reader math font

`DejaVuMathTeXGyre.ttf` is the DejaVu Math TeX Gyre font. It is distributed
under the DejaVu Fonts license; the font metadata records the Bitstream
copyright notice and states that the DejaVu changes and math extensions are in
the public domain.
