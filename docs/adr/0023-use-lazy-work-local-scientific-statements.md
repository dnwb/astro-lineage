# Use lazy Work-local Scientific Statements

Scientific Statements provide Work-local identities for assumptions, claims, predictions, and results, with Evidence anchored to concrete Versions. They may be explicit or curator-inferred; inferred Statements require a normalized reason, concrete Evidence, and independent review. Canonical wording is a semantic paraphrase while source excerpts remain Evidence. Edges may reference source or target Statements, but Statements are created only when they provide real referential value rather than as an exhaustive extraction of every sentence.
