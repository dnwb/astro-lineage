# Implement a minimal Publication Graph

V0.1 freezes `Version.kind` as `arxiv_revision | journal_manifestation` and implements belongs_to from Version to Work, revises from a later curated arXiv revision to an earlier curated revision, and published_as from one explicitly justified arXiv revision to a journal manifestation. Concern-file `work_id` is the canonical belongs_to expression, while revises and published_as are explicit records in `versions.yaml`. Revises requires the same Work and arXiv identity, increasing revision number, noncontradictory comparable dates, and an acyclic graph without implying adjacency; published_as requires same-Work arXiv-to-journal kinds but no date ordering, is never derived from Work membership or treated as textual identity, and erratum and retraction relations remain deferred.
