# Use Work bundles and global Edge records

`content/` is the sole canonical production-content root. Every Work has the complete fixed seven-file bundle, Scientific Edges remain one-file-per-record, Physics Ontology uses one file per axis, and V0.1 Method Taxonomy uses one file. Research Lines and Learning Paths use their own YAML-plus-reading-prose bundles and own contextual membership and order, while Work pages consume reproducible generated reverse indexes rather than duplicate editorial relations.
