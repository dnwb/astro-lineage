# Minimal design

Successful Astro build -> offline extraction of archive HTML -> immutable content-addressed monthly text bundles in `.cache/notebooklm/export.json` -> post-build HTTP synchronization through the updated NotebookLM skill's maintained upstream CLI. Group daily reports by Gregorian year and weekly reports by ISO year/Thursday month. Split oversized monthly bundles. No extra analysis or evidence upgrade.

Use existing JSON atomic writes and refresh locks. Remote source names contain the bundle key and full content hash, allowing reconciliation after remote-success/local-crash. Verify indexed content before recording success. Default account/storage selection belongs to the updated skill; explicit `NOTEBOOKLM_AUTH_STATE` remains supported. No implicit browser launch or relogin. Authentication failures are explicit and do not block independent channel delivery. Export/build/tests stay offline.

2026-10-02 migration: live read-only inventory confirmed the existing annual notebook and zero sources; the new skill's default profile passed passive authentication. Reuse that notebook rather than create another. Initial HTTP migration retains prior source revisions and user sources; any automatic predecessor cleanup needs a separately verified ownership/replacement gate, not a title-prefix-only deletion.

Actual failure-driven fixes: an unrecorded concurrent `dist/` build left cached build IDs matching but HTML hashes different. Require each report's safe route and current page hash before contacting NotebookLM; the regression failed before this guard and passes afterward. The first plain `.txt` upload was indexed as Markdown (heading/math markers transformed), so it remained unconfirmed and was renamed with an `import-format-unverified` prefix without deletion. Literal fenced-text upload protects the source representation; strict indexed text and source identity verification remain unchanged. HTTP subprocess groups receive SIGTERM cleanup before bounded SIGKILL escalation, preventing live child uploads after lock release.
