# Close the V0.1 decision frontier before authority migration

The V0.1 domain and governance decision frontier closed on 2026-09-03 after shared-understanding confirmation. Authority migration classifies every apparent omission as already decided but not yet migrated, superseded by a later decision, or genuinely new; only the third category reopens the frontier. This prevents legacy wording and reversible implementation detail from turning migration into unbounded domain redesign.
