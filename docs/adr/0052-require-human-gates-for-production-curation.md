# Require Human gates for production curation

Curation Provenance references a global immutable Actor Registry whose records distinguish human and agent actors and grant five controlled capabilities without storing credentials. V0.1 Agents receive only `draft_records`; Human-only actions require explicit capabilities enforced at the event time. Agent-created reader-facing records remain unreviewed until a Human Review Gate is satisfied, production independent review and Controlled Term activation require eligible Humans, and different agents do not constitute review independence.
