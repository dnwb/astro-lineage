# Separate bibliographic provenance

Version metadata and Publication Relations use Bibliographic Provenance independently from Scientific Evidence and Curation Provenance. Every stored non-derived bibliographic fact maps a record-relative RFC 6901 JSON Pointer to reusable Work-local source IDs. Each source is an immutable retrieval attestation distinct from its upstream provider-record identity, so refresh creates a new source rather than overwriting history; drift becomes updated field provenance and preserved discrepancy records with append-only Human resolutions.
